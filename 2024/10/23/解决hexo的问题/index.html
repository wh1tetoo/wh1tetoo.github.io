解决hexo的问题

2024/10/23 程序猿 hexo

检查网络连接

确保你的网络可以正常访问 GitHub，使用以下步骤来验证：

  • 打开命令行并尝试 ping GitHub：
ping github.com

如果你无法 ping 通 GitHub，说明你的网络存在连接问题，可能是网络设置或防火墙阻止了对 GitHub 的访问。

测试端口 443: 如果网络能访问但端口 443 被阻止，你可以使用以下命令测试端口 443 的连接：

Copy code
curl -I https://github.com

如果无法获得响应，说明端口 443 可能被你的网络或防火墙阻止，检查防火墙或代理设置。

    1. 代理服务器问题
      如果你在使用代理服务器或公司网络，有时代理服务器可能会阻止对 GitHub 的访问。你可以通过以下步骤配置代理：

设置 HTTP 和 HTTPS 代理：

git config --global http.proxy http://proxyserver:port
git config --global https.proxy https://proxyserver:port

如果你不使用代理，可以禁用代理：

git config --global --unset http.proxy
git config --global --unset https.proxy
    1. 切换到 SSH 方式
      如果 HTTPS 连接到 GitHub 不稳定，建议改用 SSH 方式，这样可以绕过 HTTPS 的 SSL 错误。步骤如下：

生成 SSH 密钥（如果还没有）：

ssh-keygen -t rsa -b 4096 -C "your_email@example.com"

然后根据提示将密钥存储在默认位置（一般在 ~/.ssh/id_rsa）。

将 SSH 公钥添加到 GitHub： 复制你的 SSH 公钥内容：

cat ~/.ssh/id_rsa.pub

然后将其添加到你的 GitHub 账户中的 SSH keys 中。

切换 Git 远程仓库为 SSH： 使用以下命令更改 Git 远程仓库地址：

git remote set-url origin git@github.com:wh1tetoo/wh1tetoo.github.io.git

测试 SSH 连接： 运行以下命令来测试 SSH 连接是否成功：

ssh -T git@github.com

如果成功，会看到：

Hi username! You've successfully authenticated, but GitHub does not provide shell access.
